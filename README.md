# Portfolio Personal - Ivanna López Barbona

## Descripción
Landing page de portfolio personal desarrollada con HTML y CSS para la materia Front End. El proyecto presenta una carta de presentación profesional que incluye información personal, habilidades técnicas, proyectos destacados y un formulario de contacto.

## Tecnologías y Herramientas Utilizadas

### Tecnologías Base
- **HTML5**: Estructura semántica del sitio (header, nav, main, footer).
- **CSS**: Estilizado completo con diseño responsivo.

### Recursos Externos
- **Google Fonts**: 
  - Raleway (títulos y navegación)
  - Nunito (cuerpo de texto)
- **Flexbox & CSS Grid**: Para el diseño de layouts responsivos.
- **Animaciones CSS**: 
  - Gradiente animado en el fondo
  - Transiciones en hover de botones y enlaces
  - Efecto flip en tarjetas de habilidades y proyectos
  - Animación fade-in en secciones

## Decisiones de Diseño

### Paleta de Colores
- **Modo Claro**: 
  - Fondo: degradado en tonos violetas (#ede9fe, #f5f3ff, #e9d5ff)
  - Texto: #4c1d95 (violeta oscuro)
  - Acentos: #9333ea (violeta)
- **Modo Oscuro**:
  - Fondo: #1e1b4b (violeta muy oscuro)
  - Texto: #f5f3ff (blanco)
  - Tarjetas: #2d2a4a

### Estructura y Layout
- **Header**: Navegación fija con botón de cambio de tema (claro/oscuro)
- **Sección Sobre Mí**: Foto de perfil con sombra y descripción personal
- **Sección Habilidades**: Tarjetas flip con iconos de tecnologías
- **Sección Proyectos**: Tarjetas flip con imágenes y enlaces a repositorios
- **Sección Contacto**: Formulario funcional con campos validados
- **Footer**: Copyright y redes sociales

### Interacciones y Animaciones
- Efecto **flip 3D** en tarjetas de habilidades y proyectos
- **Gradiente animado** en el fondo con movimiento constante
- **Transiciones suaves** en hover de botones y enlaces
- **Modo oscuro/claro** con toggle persistente
- **Animación fade-in** al cargar las secciones

### Responsive Design
El diseño se adapta a diferentes tamaños de pantalla utilizando:
- **Grid** con `auto-fit` y `minmax()` para habilidades
- **Flexbox** con `flex-wrap` y `justify-content: center` para proyectos
- **Media queries** para ajustes en dispositivos móviles
